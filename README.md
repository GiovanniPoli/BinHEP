# BinHEP

`BinHEP` is an R package. The instructions below explain how to install it directly from GitHub.

## Installation from GitHub

First, install the `remotes` package if it is not already installed:

```r
install.packages("remotes")
```

To install **BinHEP** from the `progetto` branch, run:

```r
remotes::install_github(
  "GiovanniPoli/BinHEP",
  ref = "progetto",
  force = TRUE
)
```
